## FAQ

### Is XCutors safe to use on my computer?

The provided packages are scanned and designed to be clean. However, executing third-party scripts always carries inherent risks, so use a sandbox environment when possible.

### How do I update the individual executors within XCutors?

The xcutorsLoader will check for updates to the bundled executors. You can also manually replace files in the respective executor folders and re-launch the loader.

### Do these executors work on both Windows 10 and Windows 11?

Yes, the entire XCutors collection is built and tested for compatibility with both Windows 10 and Windows 11 operating systems.

### What scripts can I run with these executors?

You can run a wide variety of Lua scripts designed for Roblox, ranging from simple UI modifications to complex automation scripts, depending on the executor's capabilities.

### Why is the archive password protected?

Password protection helps with automated scanning by some security software and ensures intentional, informed usage of the tools within.

### Can I use just one executor from the collection without the loader?

Yes, each executor folder (Volt, Synapse Z, etc.) is standalone. You can run them individually without using the xcutorsLoader for launching.

### What should I do if an executor stops working after a Roblox update?

This is common. Check the XCutors repository for updates, as we often patch the executors to work with new Roblox versions. Follow the update steps in the README.
